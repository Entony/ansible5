Роль LighHouse
=========

Установка  LightHouse для ClickHouse вместе с веб-сервером Nginx.

Переменные
--------------

| Переменная       | Значение по умолчанию   | Описание           |
|       ---        |          ---            |     ---            |
| `lighthouse_dir` | `"/var/www/lighthouse"` | Путь для размещения файлов интерфейса. |
