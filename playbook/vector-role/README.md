Роль: Vector
=========

Установка и настройка Vector

Переменные роли
--------------

| Переменная       | Значение по умолчанию | Описание             |
|     ---          |          ---          |         ---          |
| `vector_version` | `"0.34.0"`            | Версия Vector для скачивания. |
| `vector_config_dir` | `"/etc/vector"`    | Путь к директории с конфигурационными файлами. |

Использование
-------------

Добавьте роль в "requirements.yml" вашего плейбука.
